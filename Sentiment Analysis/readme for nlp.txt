# Explanation of Sentiment Analysis project
This project was to show sentimental analysis could help employers in understanding their employees better.
The dataset taken was reviews of 50 employees giving reviews of their workspace sentiments.
The dataset was cleaned, punctuations removed, removing stopwords and properly sorted along with the sentiments by using the Python program which was connected to Microsoft SQL server.
The words expressing sentiments were counted and put into the graph.
In closing, this whole sentimental analysis provided a overview of sentiments of employees towards the workplace through a graph helping the employers
understand their employees better.
